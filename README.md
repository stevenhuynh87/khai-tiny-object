# khai-tiny-object

Kế hoạch và mã nguồn cho đề tài tiny object detection (DETR, đặc trưng độ phân giải cao, điều kiện tài nguyên hạn chế) của Đinh Tấn Khải.

- `PLAN.md`: kế hoạch chi tiết 12 tháng (bản 2).
- `BRIEF_PLAN.md`: bản tóm tắt.
- `issues/README.md`: bảng 26 issue biweekly; nội dung đầy đủ nằm ở tab Issues của repo (#1 đến #26).
- `2611.07994v1.pdf`: paper nền ReDHF (arXiv 2611.07994).

Ràng buộc: 6 giờ mỗi tuần, GPU 12 GB, chỉ Python và PyTorch, không Jetson.
Cấu trúc code sẽ tạo ở Issue 01: `configs/ src/ scripts/ docs/ results/ paper/ notes/`.
